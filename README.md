# E-Commerce-end-to-end-revenue-analytics

This project analyzes the Superstore dataset to identify sales, profit, customer, product, and regional performance trends. The analysis uses SQL, Python, Pandas, and Power BI to transform raw data into actionable business insights.

##  Tools & Technologies

- Python
- Pandas
- SQL
- Power BI
- Excel
- Jupyter Notebook

##  Key Analysis

- Sales and profit performance
- Category and sub-category analysis
- Regional and state-wise performance
- Customer segment analysis
- Discount and profitability analysis
- Monthly and yearly sales trends
- Top-performing products
- Loss-making products and categories

##  Project Workflow

1. Imported and inspected the Superstore dataset.
2. Cleaned missing values, duplicates, and inconsistent data using Pandas.
3. Performed exploratory data analysis using Python.
4. Used SQL to analyze sales, profit, customers, and product performance.
5. Created calculated KPIs and business metrics.
6. Built an interactive Power BI dashboard.
7. Identified key trends and business insights.

##  Dashboard KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Customers
- Average Order Value
- Profit Margin

## Key Insights

The dashboard helps identify:
- High-performing product categories and regions.
- Products generating high sales but low profit.
- Impact of discounts on profitability.
- Customer segments contributing most to revenue.
- Regional opportunities for improving business performance.
